秘密の挙手（投票のあとにやります）

「〜がばれない」「〜がばれる」「〜が信じられる」という目的は、投票のあとの秘密の挙手で決めます。

  1. 司会が解決編を開き、最初に並んでいる文を1つずつ読み上げる。
  2. 読むたびに、その文が「本当だと思う人」が手を挙げる。
  3. 文に名前が出てくる当事者は、手を挙げない。
  4. 当事者以外の過半数が手を挙げたら、その文は「ばれた（信じられた）」。
  5. 文の中には本当ではないダミーが2つまじっている。ダミーに手を挙げても減点はない。どれがダミーかは、真相と一緒にわかる。

例：「AとBは昔、夫婦だった」→ AとBは手を挙げない。残り5人のうち3人が挙げたら「ばれた」。

「自分で指摘し」とある目的は、議論中にその人が自分の口で言っていないと達成になりません。

司会 読み上げ

十一月十七日、しし座流星群の極大の夜。長野の山の上にある私設天文台「星見ヶ丘天文台」で、毎年恒例の観測会が開かれた。空は雲ひとつない快晴、気温は氷点下二度。

観測会の決まりは一つ。二十一時から二十三時までは、星を見やすくするために、建物の外の明かりをすべて消す。足もとを照らすのは、赤いライトだけだ。

二十二時三十分、ドームで撮影をしていた台長の鳴沢修造から、全員のトランシーバーに声が届いた。「これから彗星の撮影に入る。二十三時にラウンジで大事な発表をする。それまで、誰もドームに来ないでくれ」。

二十二時四十一分、南西の空に大きな火球が流れ、広場から歓声が上がった。

二十三時。ラウンジに全員が集まった。けれど、鳴沢は来ない。二十三時七分、ドームに様子を見に行った者が、望遠鏡の足もとに倒れている鳴沢を見つけた。頭を殴られ、もう息はなかった。

山を下りる一本道は、夕方の落石でふさがっている。警察が着くのは、早くても夜明けだという。

4. 推理の筋道

  1. 本当の犯行時刻は22:40。撮影用パソコンの記録（ドーム②）で、22:40の画像だけすべての星が同じ向きの弧＝望遠鏡が揺れた（九重の知識：流れ星なら一本の線だけ）。22:44に遥香が呼んでも返事がない（遥香の録画・証言）。トランシーバーの送信は22:30が最後（ドーム⑤）。「亡くなって15〜20分」という医師の見立ては合わない。
  2. 22:40にアリバイがあやしい人。真理子（書斎）、堂島・宇佐美・志賀（駐車場。互いに見ている）、秋月・三上（広場）、九重（尾根の写真）、小早川（「トイレのあと寝ていた」。ただし三上が22:42に話しかけても返事がない）。
  3. 火球の見え方。広場からは南西の低い空が見えない（観測広場①）。火球の本体（緑・二つに割れた）が見えたのは、ドーム・駐車場・書斎の窓・尾根だけ（九重の写真、宇佐美・堂島・真理子の証言）。広場にいたはずの小早川が、LINE（ラウンジ①）にそれを書いている。同じく「緑色！」と書いた志賀は「トイレにいた」と言うが、トイレの窓は北向き（ラウンジ②）。志賀は駐車場にいて、宇佐美・堂島が見ている。
  4. 手袋。ドームの床の薄い青いゴム手袋の切れ端（ドーム④）と、望遠鏡の高い金具の青いゴム（ドーム⑥）。堂島の手袋は厚手。小早川は診察で薄い青い手袋を使う（堂島の証言）。金具は遺体を調べるときに触れる場所ではない。
  5. 動機。回顧録の最後が破られている（ドーム③）。茂みの切れ端「十二年前の今夜……白い軽自動車……観測会の客の若い女性」（観測広場④）、新聞のひき逃げ記事（ラウンジ⑤）、十二年前のアルバムの医学生「小早川」（ラウンジ④）、堂島の記憶（翌朝へこんだ白い車、大学生くらいの女の子）。
